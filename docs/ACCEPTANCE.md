# FastCat SSH 本轮验收

日期：2026-11-14（Asia/Shanghai）

范围按用户确认：本机隔离 SSH 服务验收；iCloud 先完成手动文件备份；目录历史全局共享。
本报告将代码与本机验证通过，和外部环境尚未验证，明确区分。

## 1. 技术验证

本机通过：Flutter 四端工程；dartssh2 真实 loopback SSH 认证、指纹拒绝、命令执行、SFTP
目录与文件 CRUD。隔离服务只监听 127.0.0.1，临时 host key、临时文件根目录，不执行 OS shell。

外部待验证：真实 Windows OpenSSH/PowerShell、Linux 发行版矩阵；这不是已通过的跨系统实测。

## 2. 本地客户端

本机通过：桌面三分区、手机 390×844 导航、连接表单无布局异常；全局历史去重/限额；
主机与命令保留本地冲突的合并；macOS 应用实际启动，检查工作区与表单。
macOS 原生集成测试通过真实系统 Keychain 凭据写入/读取/删除、并发配置保存。

实现：主机增删改查/搜索/分组、密码/PEM 私钥、终端标签、SFTP 文件浏览、上传下载、
重命名、空目录删除、新建目录、文本编辑冲突检测、命令收藏/参数/执行预览。
命令系统类型是标签，当前不阻止跨系统手动执行。

## 3. 备份

本机通过：AES-GCM 加密备份往返恢复、可选凭据、错误密码拒绝、密文篡改拒绝、版本拒绝。
备份包含统一全局目录历史；主机信任不迁移，新设备重新核验。
实现导入预览、合并/替换、失败时回滚、系统安全存储中的导入前恢复点。
加密运行在 compute isolate，文件由系统文档选择器读写。

iCloud 手动路径已接入通用文档选择器；用户账号下 iCloud 云端上传/另一设备下载的往返，
尚未进行，不计为已通过实测。按约定不包含自动 iCloud 备份。

## 4. 增强

本机通过：应用 Connection 层的跳板机（嵌套 SSH）、主机已信任重连不重复询问、
SOCKS5 握手、会话关闭；流式上传进度、取消不破坏原目标、临时文件清理。
实现：双会话左右分屏、分隔条调整、布局预设、本地布局持久化、手机辅助按键、
上传取消/重试、断线后手动重连。发布上传使用重命名；不支持覆盖重命名的服务器会报错，
不会自动删除原文件。

不在本轮完整实现：任意停靠、多级跳板机、自动恢复远端进程、批量执行、下载断点续传、
多任务传输队列、终端目录自动跟随、远程桌面、账号/团队服务。

## 使用限制

下载最大 100 MB、UTF-8 文本编辑最大 1 MB；上传最大 100 MB（流式）。
移动端进入后台可能断开 SSH，重新连接会创建新 shell。若需进程持久性，可在服务器使用 tmux。
导入恢复不承诺系统崩溃期间跨 JSON/Keychain 的事务原子性。

交付状态：已完成并本机验收可运行的增强版本；四端正式发布验收仍有上述外部环境门槛，
不能将此报告理解为所有平台及所有原方案扩展项均已完成。

## 0.4.0 状态、目录双栏与命令流程

实现内容：
- 连接终端下显示硬件/网络摘要，可打开详情、手动刷新；每 5 秒只读采集。Linux 使用 /proc、uname、df，
  Windows 使用 PowerShell/CIM/在线网卡统计。首次 CPU/网速显示采样中，读取失败保留终端并明确显示状态。
  SSH 时间包含远端命令处理，不能理解为纯 ICMP 延迟；网速汇总可能包含虚拟网卡重复流量。
- 工具文件区：左侧可展开/折叠目录树，右侧只显示当前目录文件，保留上传下载、文件编辑和菜单操作。

- 点击服务器分组名称或箭头均可折叠，并持久保存。
